# Awesome Tactile Hands [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> **Taxel Atlas**: a curated catalog of public datasets that record touch across the hand during manipulation, from human tactile gloves to dexterous robot hands with tactile skins.

Browse, filter and compare them on the [live catalog](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/), play recorded samples in the [data viewer](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/viewer/), see which models were trained on them and whether their code and weights are out on the [models page](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/models.html), see the gloves, robot hands and sensors they were recorded with on the [hardware page](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/hardware.html), and read how each dataset's hand pose was captured, with input and output formats and published accuracy, on the [hand pose page](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/pose.html).

**Kept current every night.** At 01:30 New York time a scan of arXiv, OpenAlex citations of the catalogued papers, Hugging Face and GitHub queues new papers and repositories for review, including older ones earlier passes missed; at 04:30 every catalogued link is fingerprinted and anything that changed (new files, a lifted gate, code or weights released) is rechecked. Accepted changes go live at 09:00. How it works and its rules: [pipeline/NIGHTLY.md](pipeline/NIGHTLY.md).

**What gets in.** Tactile sensing *on the hand* (glove or robot hand), recorded while the hand manipulates objects, with data that is released or announced. Each entry states which regions are sensed (fingertips, finger segments, palm), how many taxels per hand, what else is recorded in sync, and how to get it. Numbers are as the authors report them; anything we could not confirm from a primary source is marked as not stated.

**What stays out.** Contact estimated from cameras, pressure pads under the hand, or thermal contact maps on objects (PressureVision, EgoPressure, ContactPose, ContactDB); parallel-jaw grippers; tactile hardware papers with no data.

## Ranks

The rank follows how open the data is and whether its files passed four integrity checks. The license does not change the rank; each entry states it separately.

| rank | meaning | datasets |
|---|---|---|
| `R1` Open, checked | public download; sample episodes opened in the viewer and every integrity check passed | ActionSense, ADL-21, EgoTactile, EgoTouch, OpenTouch, T-Rex, Tactile textiles |
| `R2` Open, not checked | public download; the files have not been opened yet | 3dtacdex, Daimon-Infinity DM-DataDex, DECO-50, DexTacWAM, Dexterous Grasp Stability, DextraVerse, Ego-Tactile Manipulation, EgoTac-SC, FEEL, FEEL-Benchmark, FeelSight, Fixed Viewpoint Tactile Dataset, FusionX Multimodal Sample Data, Gentle Grasping (LASR), Grasp Like Humans, HumanTouch, juqiao glove 0929, LET-Dex, PalmDex, PiMForce, PULSE, RoCo Task Board Assembly, Sharpa North-FTP-1, SharpaDex v1.0, Sparsh-skin dataset, Sparsh-X dataset (Allegro part), STAG, SynData glove-with-tactile, TachinTactileGlove-Demo01, UMI-Dex-Pro-L6, UVTA, VinT-6D |
| `R3` Open, defects found | public download; sample episodes opened and at least one integrity check failed | HATO, HRDexDB, Humanoid Everyday, Reach&Grasp, T-Dex, VTDexManip |
| `R4` Apply for access | the data downloads after a form, a Hugging Face gate or the authors' approval | ACE-Data-0, HandSense (Glove2Hand), Kaiwu, Robotic Origami Challenge, TouchScale |
| `R5` Sample only | only a sample or part of the data is released | DexUMI, EgoExplorer, H-Tac DeskTask-Tac, OSMO, PX OmniSharing DB (sample data), TactAlign |
| `R6` Paper only | announced or described in a paper; no data released | Dex-MPTD, DexViTac, Humanoid VTA, RoboTacDex, TACROSS, TactiDex, VICON |

The integrity checks run on the sample episodes converted for the [viewer](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/viewer/):

- **Files open**: every sampled file opens in its documented format.
- **Streams present**: tactile and every listed stream are in the files, none empty.
- **Time base**: timestamps or a stated rate align the streams.
- **Tactile intact**: tactile channels and frames are not lost or corrupted.

A check fails when a fault affects more than 5% of a stream's recordings, channels or frames, or when the release has neither timestamps nor a stated rate; smaller faults are listed as minor. Recordings missing against the paper's count are scope, not integrity, and are listed in the caveats.

Failed checks:

- HATO, tactile intact: The right hand's middle fingertip (6 of the 60 touch sites) reads zero in all 3 converted episodes, and every wine-pouring episode sampled has the right hand's touch bytes corrupted in most steps.
- HRDexDB, streams present: tactile.npy is empty (0 elements) in all 618 Inspire RH56DFTP episodes, 23% of the 2,703 released sequences; only a 6-channel actuator force.npy is present.
- Humanoid Everyday, tactile intact: observation.tactile.values is shifted by 13 values (a recording-code bug), so only 22 of the 66 Dex3-1 readings survive (12 left, 10 right); the viewer undoes the shift.
- Reach&Grasp, tactile intact: 4 of the 58 taxels are faulty: ring-fingertip rdd, rdo and rdm malfunction (stated in the paper), and lmo reads 0 in all 158 tactile files.
- T-Dex, streams present: Depth files are empty (800-byte HDF5 with no datasets) in 5 of the 70 recordings: play 16, 19 and 21, book_opening 7 and 8.
- VTDexManip, time base: The release has no timestamps and no frame rate; tactile and video frames pair one to one, and the viewer assumes 30 fps.

## Models

**26** models trained or evaluated on touch recorded across a hand; 17 released code and 13 released weights. Filters and the datasets each one uses are on the [models page](https://yuxiang-ma.github.io/Awesome-Tactile-Hands/models.html).

### World models

- [DexTouch-WM](https://arxiv.org/abs/2609.20649) - world model. Takes an initial RGB frame, both hands' 320-taxel pressure maps, a language instruction and a 67-D future pose sequence (wrists, two 20-DoF hand configurations retargeted to the Wuji hand, head camera) and predicts future RGB frames and tactile maps, for human hands and a Wuji robot hand wearing the same glove layout. Uses HumanTouch (pretraining); code not released, weights not released. IROS 2026 Workshop RoBoWoMo (arXiv 2609.20649) ([paper](https://arxiv.org/abs/2609.20649)).
- [DTWM](https://adonis-galaxy.github.io/dtwm-project-page/) - world model. Takes 13 egocentric RGB frames, rendered hand skeletons, both gloves' pressure and flexion readings and a task instruction and predicts the next 36 frames (1.2 s) of human bimanual manipulation video, using Wan2.2-Fun-5B-InP with LoRA and each hand's touch added to the video tokens at that hand's image location. Uses EgoTouch (training); code released, weights not released. arXiv 2609.34286 ([paper](https://arxiv.org/abs/2609.34286), [code](https://github.com/Adonis-galaxy/Dexterous-Tactile-World-Model)).

### Policies

- [DECO](https://baai-humanoid.github.io/DECO-webpage/) - policy. 80M-parameter diffusion transformer with separate conditioning paths for vision, proprioception and touch, plus a tactile adapter that tunes under 10% of the weights; head-camera images, joint states and the 1,062-taxel readings of each Inspire RH56DFTP hand go in, and bimanual action chunks for a Unitree H1-2 come out. Uses DECO-50 (training); code released, weights released. ICML 2026 (arXiv 2602.05513) ([paper](https://arxiv.org/abs/2602.05513), [code](https://github.com/BAAI-Humanoid/DECO), [weights](https://huggingface.co/BAAI-Humanoid/DECO_sim)).
- [DexTacWAM](https://dextacwam.github.io/) - policy. Takes head and wrist RGB, per-finger gel images (5 per hand) and hand pose from two 22-DoF Sharpa Wave hands, jointly denoises future visual and tactile latents in a 2B Genie Envisioner video model, and outputs actions (relative end-effector pose, hand targets and 60 fingertip wrench values) from a 160M action expert. Uses T-Rex (pretraining), DexTacWAM (training); code released, weights released. arXiv 2609.24976 ([paper](https://arxiv.org/abs/2609.24976), [code](https://github.com/dextacwam/DexTacWAM), [weights](https://huggingface.co/JensenYuan/DexTacWAM_multi_finger_tactile_encoder)).
- [FTP-1](https://ftp1-policy.github.io/) - policy. Takes language, multi-view RGB, proprioception and touch from image, array or state sensors (21 sensor types in pretraining) mapped to 24 functional-area tokens and outputs action chunks in a unified action space; built on pi0.5 with a 300M-parameter tactile expert, pretrained on about 3,000 h of human-glove, dexterous-hand and gripper data and fine-tuned on 5 hardware setups. Uses EgoTac-SC (pretraining), Sharpa North-FTP-1 (pretraining), Humanoid Everyday (pretraining), LET-Dex (pretraining), DexUMI (pretraining), OpenTouch (pretraining), PX OmniSharing DB (sample data) (pretraining); code released, weights released. arXiv 2606.13102 ([paper](https://arxiv.org/abs/2606.13102), [code](https://github.com/michaelyuancb/ftp1-policy), [weights](https://huggingface.co/MJJJJ1064/ftp1_v0426_50kstep)).
- [T-Rex](https://tactile-rex.github.io/) - policy. Vision-language-action model on a Qwen3-VL-2B backbone with latent, action and tactile experts; head and wrist RGB, language and temporal VQ-VAE codes of the ten fingertip deformation and force streams go in, and joint actions for two Sharpa Wave hands on a Dexmate Vega-1 come out, with action chunks at about 5 Hz refined by touch at about 20 Hz. Uses T-Rex (training), UVTA (fine-tuning); code released, weights released. arXiv 2606.17055 ([paper](https://arxiv.org/abs/2606.17055), [code](https://github.com/ZhuoyangLiu2005/T-Rex), [weights](https://huggingface.co/miniFranka/T-Rex_midtrain_mecka23k_ucb100_vqvae_epoch6)).
- [TACROSS](https://tacross-touch-project.github.io/) - policy. Canonicalizers, per-sensor residual adapters and a shared temporal transformer map a 285-point piezoresistive glove and the capacitive Revo2 robot hand into a 256-D contact latent; an ACT policy takes the robot's touch latent, RGB and state and outputs arm and Revo2 hand actions, while human demonstrations train the tactile encoder and add confidence-weighted auxiliary targets. Uses TACROSS (training); code announced, weights not released. arXiv 2610.11945 ([paper](https://arxiv.org/abs/2610.11945)).
- [TactAlign](https://yswi.github.io/tactalign/) - policy. Human touch (OSMO glove, 3-axis magnetic fingertip) and robot touch (30-taxel Xela fingertip on an Allegro hand) are encoded by separately pretrained JEPA-style encoders and mapped into a shared latent by a rectified flow trained on pseudo-pairs from unpaired demonstrations; human and robot data then co-train an Allegro-on-Franka policy. Uses TactAlign (training); code announced, weights not released. arXiv 2602.13579 ([paper](https://arxiv.org/abs/2602.13579)).
- [TactiSkill](https://tactidex.github.io/) - policy. PPO residual policy on top of a frozen kinematic imitation policy that tracks TactiDex human hand-object sequences with simulated Inspire hands; proprioception, an object point-set code, five fingertip contact targets derived from the human glove and future reference kinematics go in, residual joint targets come out, and training uses a three-part tactile reward. Uses TactiDex (training); code announced, weights not released. ACM MM 2026 (arXiv 2607.09190) ([paper](https://arxiv.org/abs/2607.09190)).
- [TouchWorld](https://phanes-lab.github.io/TouchWorld-website/) - policy. Takes head and wrist camera images, tactile-glove pressure rendered as images, proprioception and a task instruction on a humanoid with two Wuji hands and outputs 32-step action chunks, guided by 17-frame visual-tactile subgoals from a Wan2.2-TI2V-5B tactile world model and corrected by a residual transformer that reads recent touch. Uses EgoTouch (pretraining); code not released, weights not released. arXiv 2607.07287 ([paper](https://arxiv.org/abs/2607.07287)).
- [TTP](https://research.beingbeyond.com/ttp) - policy. Transferable Tactile Pre-Training extends the Being-H0.5 vision-language-action model with touch in a 351-taxel MANO-surface space shared by human and robot hands and a tactile expert that predicts future touch; pretrained on 160 h of human and simulated data with glove-measured or derived contact, then post-trained on Inspire hands, DexBotic hands and DM-Tac grippers. Uses H-Tac DeskTask-Tac (pretraining); code released, weights released. arXiv 2607.01067 ([paper](https://arxiv.org/abs/2607.01067), [code](https://github.com/BeingBeyond/TTP), [weights](https://huggingface.co/BeingBeyond/TTP)).
- [UVTA](https://uni-vta.github.io/) - policy. Diffusion policy (ViT-S/8 visual encoder, U-Net denoiser) that puts exoskeleton-glove and Sharpa Wave robot demonstrations in shared touch and action spaces; wrist RGB and 20 fingertip-region touch values go in, and 16-step chunks of 9-D wrist and 22-D hand actions plus future touch come out, with only robot actions executed on a Sharpa North right arm. Uses UVTA (training); code released, weights not released. arXiv 2609.34182 ([paper](https://arxiv.org/abs/2609.34182), [code](https://github.com/uni-vta/UVTA)).
- [TK-STGN](https://grasplikehuman.github.io/) - policy. Tactile-Kinesthetic Spatio-Temporal Graph Network; readings of a data glove's 25 force-sensitive pads and joint angles, encoded as a graph in polar coordinates, go in, and per-joint states come out, which force-position hybrid control turns into robot-hand commands; the same glove is worn by human demonstrators and by the robot hands. Uses Grasp Like Humans (training); code not released, weights not released. IEEE T-RO (accepted; arXiv 2509.08354) ([paper](https://arxiv.org/abs/2509.08354)).
- [T-Dex](https://tactile-dexterity.github.io/) - policy. Two-phase method for an Allegro hand with 15 XELA uSkin pads on a Kinova Jaco arm; a tactile encoder pretrained with BYOL on robot play data embeds the tactile image, and a nearest-neighbour policy combines it with camera features to retrieve robot actions from 6 demonstrations per task. Uses T-Dex (training), 3dtacdex (training), Sparsh-skin dataset (training); code released, weights released. CoRL 2023 (arXiv 2303.12076) ([paper](https://arxiv.org/abs/2303.12076), [code](https://github.com/irmakguzey/tactile-dexterity), [weights](https://drive.google.com/file/d/1G52ihW7EbE5eSe04jnxGpo7cc1jxYWHw/view)).

### Tactile representations

- [3DTacDex](https://3dtacdex.github.io/) - tactile representation. Graph encoder (GraphMAE backbone) for 3D tactile data; taxel positions and 3-axis forces from 8 PaXini pads on a LEAP hand, in a canonical hand-frame representation, go in, it is pretrained on play data by masked local-force and net-force prediction, and its features condition a diffusion policy. Uses 3dtacdex (training); code released, weights released. ICRA 2025 (arXiv 2409.17549) ([paper](https://arxiv.org/abs/2409.17549), [code](https://github.com/tianhaowuhz/3dtacdex), [weights](https://github.com/tianhaowuhz/3dtacdex/tree/main/ckpts)).
- [Sparsh-skin](https://akashsharma02.github.io/sparsh-skin-ssl/) - tactile representation. Encoder pretrained by self-distillation for the 18 Xela uSkin pads on an Allegro hand; a short history of 3-axis magnetic readings and 3D sensor positions goes in, and a full-hand tactile embedding comes out, tested on force, joystick-state and object-pose estimation and a plug-insertion policy. Uses Sparsh-skin dataset (pretraining); code released, weights released. CoRL 2025 (arXiv 2505.11420) ([paper](https://arxiv.org/abs/2505.11420), [code](https://github.com/facebookresearch/sparsh-multisensory-touch), [weights](https://huggingface.co/facebook/sparsh-skin)).
- [Sparsh-X](https://akashsharma02.github.io/sparsh-x-ssl/) - tactile representation. Transformer encoder pretrained by self-supervision on ~1M Digit 360 contact interactions that fuses tactile image, contact audio, IMU and pressure into one embedding; tested in plug-insertion imitation learning and in-hand rotation on an Allegro hand with four Digit 360 fingertips, and on object-action, material-quantity and force estimation. Uses Sparsh-X dataset (Allegro part) (pretraining); code released, weights released. CoRL 2025 (arXiv 2506.14754) ([paper](https://arxiv.org/abs/2506.14754), [code](https://github.com/facebookresearch/sparsh-multisensory-touch), [weights](https://huggingface.co/facebook/sparsh-x-all)).
- [VT-JointPretrain](https://lqts.github.io/VTDexManip/) - tactile representation. Masked-reconstruction transformer pretrained on human egocentric frames paired with 20-pad glove readings; an image and 20 tactile values go in, and its CLS feature conditions an RL policy for a Shadow Hand fitted with 20 matching force sensors, on 6 Isaac Gym tasks and a real Shadow Hand test. Uses VTDexManip (pretraining); code released, weights released. ICLR 2025 ([paper](https://proceedings.iclr.cc/paper_files/paper/2025/file/e19b6f65791e350347bcff8a3955cb5b-Paper-Conference.pdf), [code](https://github.com/LQTS/VTDexManip), [weights](https://1drv.ms/f/c/9054151f0ba654c9/EsZlIVlJEudEpYT2Ofl7tj8BbNErfoJZdkgG5PnZ5j6_hg)).

### Estimation (touch from other signals, or state from touch)

- [EgoPressureDiff](https://egotactile.github.io/) - estimation. Conditional video diffusion model adapted from Stable Video Diffusion img2vid-xt; an egocentric RGB clip, contact hint masks, a text prompt with object and subject attributes such as weight and material, and a hand-pressure prototype go in, and a pressure heatmap sequence for the human hand comes out, convertible to the glove's 162 sensors. Uses EgoTactile (training), ACE-Data-0 (evaluation); code released, weights not released. ICML 2026 (arXiv 2606.09243) ([paper](https://arxiv.org/abs/2606.09243), [code](https://github.com/Russell-Zeng/EgoTactile)).
- [EgoPressureFormer](https://egotactile.github.io/) - estimation. Discriminative baseline on a TimeSformer backbone; a 16-frame egocentric RGB clip goes in, learnable sensor queries attend to the video tokens, and the 162-sensor pressure sequence of the gloved human hand comes out, trained with per-sensor classification and a frame-level contact gate. Uses EgoTactile (training); code not released, weights not released. ICML 2026 (arXiv 2606.09243) ([paper](https://arxiv.org/abs/2606.09243)).
- [EgoTac](https://egotac.github.io/) - estimation. Takes 4 egocentric RGB frames (1 in the image variant) and predicts per-vertex force and contact on the 778-vertex MANO mesh of each human hand, using a DINOv2 encoder, temporal cross-attention and an AdaLN transformer decoder. Uses EgoTac-SC (training), OpenTouch (evaluation); code released, weights released. NeurIPS 2026 (arXiv 2608.15060) ([paper](https://arxiv.org/abs/2608.15060), [code](https://github.com/Mr-Zwkid/EgoTac), [weights](https://huggingface.co/wkzhang/EgoTac)).
- [TouchAnything](https://jianyi2004.github.io/TouchAnything-Website/) - estimation. An 8-frame egocentric RGB clip, optional left and right wrist views and 42 WiLoR hand joints go in, and a 21x21 pressure map for each human hand comes out; wrist views are dropped at random in training so it also runs on the egocentric view alone. Uses EgoTouch (training), TouchScale (training), EgoTactile (evaluation), ACE-Data-0 (evaluation); code released, weights not released. arXiv 2605.13083 ([paper](https://arxiv.org/abs/2605.13083), [code](https://github.com/Jianyi2004/TouchAnything)).
- [TouchSight](https://arxiv.org/abs/2609.20414) - estimation. Takes 8 egocentric RGB frames and predicts force on 275 glove taxels per hand plus palmar MANO contact for both human hands, from frozen DINOv3 and VGGT features decoded by 10 region queries per hand, with no hand reconstruction at inference. Uses HumanTouch (training); code not released, weights not released. arXiv 2609.20414 ([paper](https://arxiv.org/abs/2609.20414)).
- [NeuralFeels](https://suddhu.github.io/neural-feels/) - estimation. Online visuo-tactile SLAM for an Allegro hand with four DIGIT fingertips; segmented RGB-D depth, DIGIT images converted to contact depth by a pretrained tactile transformer, and joint proprioception go in, and the held object's pose and a neural-field shape come out. Uses FeelSight (evaluation); code released, weights released. Science Robotics 2024 (arXiv 2312.13469) ([paper](https://arxiv.org/abs/2312.13469), [code](https://github.com/facebookresearch/neuralfeels), [weights](https://huggingface.co/suddhu/tactile_transformer)).
- [PiMForce](https://hci-tech-lab.github.io/PiMForce/) - estimation. 8-channel forearm sEMG and a 3D hand pose (MANUS glove in training, a single-RGB hand-pose estimate in qualitative tests) go in, and pressure from 0 to 20 N for nine regions of the human right hand comes out, supervised by a 65-node pressure glove and five fingertip sensors. Uses PiMForce (training); code released, weights released. NeurIPS 2024 (arXiv 2410.23629) ([paper](https://arxiv.org/abs/2410.23629), [code](https://www.dropbox.com/scl/fo/m7qye1l3ii6hlwgzlajyv/AAszkuRRMYwZ6OtmPWPlRxs/Codes?rlkey=eyt5gs66uimhiw3dismnylamw&dl=0), [weights](https://www.dropbox.com/scl/fo/m7qye1l3ii6hlwgzlajyv/ADrSa2qEfM-GUzzrE35r5Sk/Codes/Checkpoints?rlkey=eyt5gs66uimhiw3dismnylamw&dl=0)).
- [VinT-Net](https://vint-6d.github.io/) - estimation. Baseline for in-hand 6D object pose on Tencent's TRX-Hand; RGB-D images, touch points from the hand's tactile skin and finger proprioception are fused by a sensing-aggregation module, and a 3D keypoint module with least-squares fitting outputs the held object's pose. Uses VinT-6D (training); code announced, weights not released. ICML 2024 (arXiv 2501.00510) ([paper](https://arxiv.org/abs/2501.00510)).

Add or correct an entry by editing [`data/datasets.json`](data/datasets.json), [`data/models.json`](data/models.json) or [`data/hardware.json`](data/hardware.json) and running `python3 scripts/build_readme.py`, or [open an issue](../../issues/new/choose). ## Repository layout

| path | contents |
|---|---|
| `data/datasets.json` | the catalog: one record per dataset, the single source of truth |
| `data/hardware.json` | tactile gloves, tactile robot hands and add-on sensors, each with the catalog datasets recorded with it |
| `data/models.json` | models trained or evaluated on hand touch: the catalog datasets each one uses, and its code and weights release |
| `data/changes/` | the change log, one file per nightly run (collected into `data/changes.json` for the site) |
| `index.html`, `models.html`, `hardware.html`, `assets/` | the catalog, models and hardware pages (static, no build step) |
| `viewer/` | the synchronized video / tactile / hand-pose player; its media is served from the Hugging Face dataset [`yxma/human-mcap-viewer-media`](https://huggingface.co/datasets/yxma/human-mcap-viewer-media) |
| `scripts/build_readme.py` | validates the catalog files, derives rank, contents and used_by, and regenerates the lists above |
| `scripts/watch.py`, `scripts/discover.py`, `scripts/nightly_*`, `scripts/publish_nightly.py`, `watch/` | the nightly checks: scans, the review wrapper, the guard, the 09:00 publish, and their state ([pipeline/NIGHTLY.md](pipeline/NIGHTLY.md)) |
| `scripts/fetch_thumbs.py` | caches each dataset's overview figure in `assets/thumbs/` and each device photo in `assets/hw/` |
| `pipeline/` | how a dataset is surveyed, sampled, converted for the viewer and checked |
